# hide story ig

ส่วนขยาย (Extension) สำหรับ **Microsoft Edge** ที่ช่วยจัดการรายชื่อ "ซ่อนสตอรี่" บน Instagram Web
สร้างกลุ่มรายชื่อไว้ล่วงหน้า แล้วกดครั้งเดียวให้ส่วนขยายค้นหาและติ๊กซ่อนสตอรี่ทีละคนให้อัตโนมัติ

> ⚠️ **เครื่องมือนี้ไม่เป็นทางการ** ไม่ได้เกี่ยวข้องกับ Instagram หรือ Meta
> ทำงานโดยจำลองการคลิกบนหน้าเว็บ Instagram จึงอาจพังได้เมื่อ Instagram เปลี่ยนหน้าเว็บ
> และอาจขัดกับข้อกำหนดการใช้งานของ Instagram โปรดใช้กับบัญชีของตัวเองและรับความเสี่ยงเอง

## ✨ ฟีเจอร์

- 🗂 **กลุ่มรายชื่อ** – สร้าง แก้ไข เปลี่ยนชื่อ และลบกลุ่ม username ได้ไม่จำกัด
- 🙈 **ซ่อนทั้งกลุ่ม** – เลือกกลุ่มจาก dropdown แล้วกดซ่อน ระบบค้นหาทีละคนและติ๊กให้เป็นสีฟ้า (คนที่ซ่อนอยู่แล้วจะข้าม)
- 👁 **เอาออกจากการซ่อน** – เอาออกเฉพาะคนในกลุ่ม หรือเอาออกทั้งหมด
- 🔍 **เช็กรายชื่อที่ซ่อนอยู่** – อ่าน 50 แถวแรกของรายการ แล้วแสดงว่าใครถูกซ่อนอยู่
- 💾 **บันทึกผลการเช็กเป็นกลุ่ม** – เปลี่ยนรายชื่อที่ซ่อนอยู่ให้เป็นกลุ่มได้ทันที
- 📤 **ส่งออก / นำเข้ากลุ่ม** – สำรองข้อมูลเป็นไฟล์ JSON หรือวางข้อความ JSON เพื่อนำเข้า
- ⏹ **ปุ่มหยุด** – หยุดการทำงานได้ตลอด
- 🌗 รองรับโหมดมืด/สว่างตามระบบ

## 📦 การติดตั้ง

ยังไม่ได้อยู่บน Edge Add-ons ติดตั้งแบบ Load unpacked ดังนี้

1. ดาวน์โหลดโปรเจกต์นี้ (**Code → Download ZIP** หรือโหลดจากหน้า **Releases**) แล้วแตกไฟล์
2. เปิด Edge ไปที่ `edge://extensions`
3. เปิด **Developer mode** (มุมซ้ายล่างหรือขวาบน)
4. กด **Load unpacked** แล้วเลือกโฟลเดอร์ที่มีไฟล์ `manifest.json`
5. (แนะนำ) ปักหมุดไอคอนไว้บนแถบเครื่องมือ

> ต้อง **ล็อกอิน Instagram** บน Edge ไว้ก่อนใช้งาน

## 🚀 วิธีใช้

### 1) สร้างกลุ่ม
1. คลิกไอคอน Extension → แท็บ **กลุ่ม** → **กลุ่มใหม่**
2. ตั้งชื่อกลุ่ม ใส่ username บรรทัดละ 1 คน (ใส่ `@` หรือไม่ใส่ก็ได้) แล้วกด **บันทึก**

หรือจะให้สร้างจากรายชื่อที่ซ่อนอยู่แล้วก็ได้: แท็บ **ซ่อนสตอรี่** → **เช็กที่ซ่อนอยู่** → ตั้งชื่อ → **บันทึก**

### 2) ซ่อน / เอาออก
1. แท็บ **ซ่อนสตอรี่** → เลือกกลุ่ม
2. กด **ซ่อนกลุ่มนี้** (หรือ **เอาออก**)
3. Extension จะเปิดหน้า `instagram.com/accounts/hide_story_and_live_from/` ให้อัตโนมัติ
   แล้วค้นหาและติ๊กทีละคน ระหว่างนั้นอย่าปิดหรือสลับแท็บ
4. ดูสรุปผลที่ popup: ซ่อนใหม่ / ซ่อนอยู่แล้ว / ไม่พบหรือไม่สำเร็จ

### 3) สำรองข้อมูล
แท็บ **กลุ่ม** → **ส่งออก** เพื่อดาวน์โหลดไฟล์ JSON และ **นำเข้า** เมื่อต้องการกู้คืน (ชื่อกลุ่มซ้ำจะถูกทับ)

รูปแบบไฟล์:

```json
{
  "app": "hide-story-ig",
  "version": 1,
  "groups": {
    "ที่ทำงาน": ["user_one", "user_two"],
    "ญาติ": ["user_three"]
  }
}
```

## ⚙️ หลักการทำงาน

- `popup.html / popup.css / popup.js` – หน้าตาและตรรกะของ popup, จัดเก็บกลุ่มใน `chrome.storage.local`
- `content.js` – สคริปต์ที่ทำงานบน `www.instagram.com` ทำหน้าที่หาช่องค้นหา, พิมพ์ username, หาแถวผลลัพธ์,
  ตรวจว่าติ๊กอยู่หรือไม่ (ดูจากไอคอน/สี) และจำลองการคลิก
- `manifest.json` – Manifest V3

สิทธิ์ที่ขอ:

| สิทธิ์ | ใช้เพื่อ |
|---|---|
| `storage` | เก็บกลุ่มรายชื่อในเครื่อง |
| `tabs` | เปิด/ตรวจแท็บหน้า Hide story |
| `https://www.instagram.com/*` | ให้สคริปต์ทำงานบนหน้า Instagram |

## 🔒 ความเป็นส่วนตัว

- ไม่มีเซิร์ฟเวอร์ ไม่ส่งข้อมูลออกนอกเครื่อง ไม่มีการวิเคราะห์ผู้ใช้
- รายชื่อกลุ่มถูกเก็บในเบราว์เซอร์ของคุณ (`chrome.storage.local`) เท่านั้น
- ไม่ต้องกรอกรหัสผ่าน Instagram ส่วนขยายทำงานผ่านเซสชันที่ล็อกอินอยู่แล้ว

## 🛠 แก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| "เชื่อมต่อหน้า Instagram ไม่ได้" | รีเฟรชหน้า Instagram (F5) แล้วกดใหม่ / เช็กว่าล็อกอินอยู่ |
| "ไม่พบรายชื่อในหน้านี้" | Instagram อาจเปลี่ยนโครงสร้างหน้า ดูหัวข้อ *ปรับแต่งโค้ด* ด้านล่าง |
| ค้นหาได้แต่ไม่ติ๊ก | ตรวจ `TOGGLE_SEL` และฟังก์ชัน `isChecked` / `realClick` ใน `content.js` |
| เช็กแล้วนับคนที่ซ่อนผิด | ฟังก์ชัน `isChecked` เดาจากไอคอน `mask-image` (`outline` = ยังไม่ติ๊ก) อาจต้องปรับ |
| อัปเดตโค้ดแล้วไม่เปลี่ยนแปลง | กดปุ่ม reload ที่ `edge://extensions` **และ** รีเฟรชหน้า Instagram |

### ปรับแต่งโค้ด

ค่าที่แก้บ่อยอยู่ใน `content.js`:

- `TOGGLE_SEL` – selector ของปุ่มติ๊กวงกลมแต่ละแถว
- `CHECK_LIMIT` – จำนวนแถวที่อ่านเมื่อกด "เช็กที่ซ่อนอยู่" (ค่าเริ่มต้น 50)
- ค่า `sleep(...)` ในฟังก์ชัน `setUsers` / `unhideAll` – ความหน่วงต่อคน
  (ถ้ากลุ่มใหญ่มาก แนะนำให้ปรับเพิ่มเพื่อลดโอกาสโดนจำกัดการใช้งาน)

ถ้าเปิด Issue ว่า "ใช้ไม่ได้" รบกวนแนบ HTML ของแถวคนหนึ่งแถว (ทั้งตอนติ๊กแล้วและยังไม่ติ๊ก) จะช่วยแก้ได้เร็วมาก

# English (short)

**hide story ig** is an unofficial Microsoft Edge extension (Manifest V3) that automates Instagram's
"Hide story and live from" list on the web. Define groups of usernames, then hide/unhide a whole group
in one click, check who is currently hidden (first 50 rows), save that result as a group, and
import/export groups as JSON. All data stays in your browser (`chrome.storage.local`).

**Install:** download/clone → `edge://extensions` → enable *Developer mode* → *Load unpacked* → select the folder with `manifest.json`.

**Disclaimer:** not affiliated with Instagram/Meta. It simulates clicks on the web UI, may break whenever
Instagram changes its markup, and may violate Instagram's Terms of Use. Use at your own risk.
